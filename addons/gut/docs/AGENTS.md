# AGENTS.md

## What this folder is
GUT (Godot Unit Test) documentation source, pinned to **GUT 9.6.1 for
Godot 4**. Use these pages as a reference when writing GUT tests in a
Godot project. The page index lives in `index.rst`; every other page is
markdown.

## File map
One line per file, grouped by topic.

### Starting out
- `Quick-Start.md` — install hint, a passing and a failing test, where to go next.
- `Creating-Tests.md` — anatomy of a test script, lifecycle hooks, inner classes.

### Doubles, stubs, spies
- `Doubles.md` — `double(...)` basics: scripts, scenes, inner classes, static-method gotchas, varargs.
- `Partial-Doubles.md` — `partial_double(...)` keeps source behavior unless stubbed.
- `Double-Strategy.md` — `INCLUDE_NATIVE` vs `SCRIPT_ONLY`; why native methods are missing by default.
- `Doubling-Singletons.md` — doubling autoloads.
- `Stubbing.md` — `stub(x.foo).to_return(...)`, `to_call_super`, `to_do_nothing`, parameter defaults.
- `Spies.md` — `assert_called`, `assert_called_count`, `get_call_parameters`.

### Async and input
- `Awaiting.md` — `wait_seconds`, `wait_idle_frames`/`wait_process_frames`, `wait_physics_frames`, `wait_for_signal`, `wait_until`, `wait_while`, `pause_before_teardown`.
- `Simulate.md` — `simulate(...)` helper for advancing frames/seconds.
- `Mocking-Input.md` — synthetic input via `InputFactory`/`GutInputSender`.

### Assertions, errors, warnings
- `Comparing-Things.md` — `assert_eq`, `assert_ne`, `assert_same`, `assert_eq_deep`; dictionary/array gotchas.
- `Error-Tracking.md` — engine errors that fail tests.
- `GDScript-Warnings.md` — why GUT triggers GDScript warnings and how to suppress them.

### Memory and lifecycle
- `Memory-Management.md` — `autofree`, `autoqfree`, `add_child_autofree`, orphan counts, `assert_no_new_orphans`.
- `Hooks.md` — `before_all`, `before_each`, `after_each`, `after_all`.
- `Global-Lifecycle-Hooks.md` — autoload pre/post run hooks.

### Other features
- `Parameterized-Tests.md` — `use_parameters(...)` and `ParameterFactory.named_parameters`.
- `Inner-Test-Classes.md` — nested `class TestFoo: extends GutTest`.
- `Export-Test-Results.md` — JUnit XML export.
- `Command-Line.md` — `gut_cmdln.gd`, all `-g*` options, `.gutconfig.json` schema.
- `New-For-Godot-4.md` — Godot 3 → 4 deltas that affect GUT usage.

### Class reference
- `class_ref/class_guttest.rst` — the main API: every assert, wait helper, double/spy/stub call. The full assert/method list lives here, not in a separate page.
- `class_ref/class_gutinputfactory.rst` — input factory.
- `class_ref/class_gutinputsender.rst` — input sender.
- `class_ref/class_gutmain.rst` — top-level test runner.
- `class_ref/class_guttrackederror.rst` — error tracking record.
- `class_ref/class_guthookscript.rst` — pre/post hook script base.
- `class_ref/class_addons_gut_cli_optparse.rst` — CLI option parser internals.
- `class_ref/class_addons_gut_junit_xml_export.rst` — JUnit XML exporter.
- `class_ref/class_addons_gut_parameter_factory.rst` — parameter factory.

## Linking style
- Wiki page: `[Title](Page-Name)` or `[Title](Page-Name.md#anchor)`.
- GUT class: `[GutTest][class_GutTest]`.
- Anchor inside an auto-generated class ref: must use raw
  `<a href="class_ref/...">`, not markdown `[...](#...)`.
  `Spies.md:10-14` documents this gotcha.
